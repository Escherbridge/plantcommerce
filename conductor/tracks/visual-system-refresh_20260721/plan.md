# Delivery plan

1. Audit current components, tokens, motion, claims, and responsive gaps.
2. Consolidate canonical tokens and accessible primitive states.
3. Migrate proven routes and components in dependency order, with truthful
   unavailable, loading, empty, and error states.
4. Run visual, keyboard, reduced-motion, contrast, and responsive verification
   as part of the integrated release gate.
