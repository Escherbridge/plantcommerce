# Visual system refresh

Evolve Aevani's existing Swiss/editorial foundation into a warm, credible,
accessible growing brand. The system is token-led and modular: tokens,
primitives, components, patterns, then route templates.

## Required outcomes

- One canonical token source for color, typography, spacing, radius, elevation,
  focus, motion, and responsive layouts.
- Documented interactive component states: default, hover, focus, disabled,
  loading, validation, empty, and error.
- WCAG 2.1 AA contrast, keyboard behavior, clear labels, reduced-motion support,
  responsive 320px through desktop layouts, and 44px touch targets.
- Purposeful feedback motion only. No marquee, text scramble, blanket reveal,
  decorative parallax, fabricated customer-count, shipping, sustainability, or
  certification claims.

## Media rule

The design system may not substitute AI mock assets for product imagery. Product
and category media must arrive through the verified catalog-media contract.
