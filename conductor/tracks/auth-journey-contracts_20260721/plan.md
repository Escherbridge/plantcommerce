# Delivery plan

1. Audit route, server-action, session, error, and capability-flag behavior.
2. Repair form semantics and truthful error/recovery states without weakening
   security controls.
3. Verify guest/auth cart transfer and authorization boundaries after the
   database rehearsal enables the underlying contracts.
4. Exercise success, failure, redirect, lockout, recovery, and logout browser
   paths in the integrated release gate.
