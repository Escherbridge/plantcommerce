# Source capture: W3C WCAG 2.2 — Target Size (Minimum)

- URL: https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html
- Fetched: 2026-07-22 (America/Denver)
- Page update: 2026-05-11
- Intent: define contemporary minimum touch/pointer target expectations for mobile commerce controls.

## Captured source facts

- Success Criterion 2.5.8 is Level AA in WCAG 2.2, not WCAG 2.1.
- Pointer targets should be at least 24 by 24 CSS pixels, with defined exceptions including adequate spacing.
- W3C recommends meeting the size minimum rather than relying on spacing, and points to the stricter 2.5.5 enhanced criterion for important controls.

## Aevani implication

Treat 24px as a floor and aim for roughly 44px activation areas for primary commerce actions, icon buttons, quantity controls, filter toggles, and checkout navigation. The visible SVG can remain optically 18–24px inside that target.
